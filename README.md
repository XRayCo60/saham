# 🏦 SahamBot & StockBot - بات تلگرام بازار سهام

<div dir="rtl">

## 📋 معرفی

این مخزن شامل پروژه‌های شبیه‌ساز بازار سهام و ارز تلگرامی با زبان C# است:
- **`StockBot/`**: نسخه جدید بات تلگرامی بازار سهام با نمودار گرافیکی ScottPlot و پشتیبانی کامل از دکمه‌های تعاملی و امکانات جدید.
- **`SahamBot.cs`**: نسخه تک‌فایلی شبیه‌ساز بازار سهام.

---

## 🚀 نصب و اجرای StockBot

### پیش‌نیازها
- .NET 8.0 SDK یا بالاتر
- اتصال اینترنت

### اجرا
```bash
cd StockBot
dotnet run
```

---

## 📝 ویژگی‌های اصلی StockBot
- پشتیبانی از دستور `/start` و منوی کاربری زیبا
- نمایش موجودی کاربران بر حسب دلار `$`
- مدیریت تصاویر و آیکون برای ارزها
- ایجاد سفارشات اولیه توسط ادمین و تعیین قیمت پایه ارزها
- نمودار قیمت‌ها با ScottPlot
- رابط کاربری جذاب با دکمه‌های تعاملی و برطرف شدن مشکلات دکمه‌ها
