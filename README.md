# 🏦 SahamBot - بات تلگرام بازار سهام

<div dir="rtl">

## 📋 معرفی

SahamBot یک ربات تلگرامی شبیه‌ساز بازار سهام است که به صورت یک فایل C# نوشته شده است.
کاربران می‌توانند ارزهای مختلف را خرید و فروش کنند، نمودار قیمت‌ها را مشاهده کنند و در رقابت با دیگر کاربران شرکت کنند.

---

## 🚀 نصب و اجرا

### پیش‌نیازها
- .NET 8.0 SDK یا بالاتر
- اتصال اینترنت

### اجرا
```bash
dotnet run
```

### ساخت فایل اجرایی
```bash
dotnet publish -c Release -o publish/
```

| دستور | توضیحات |

### دستورات بازار

| دستور | توضیحات |
|-------|---------|
| `/market` | مشاهده لیست تمام ارزها با قیمت، تغییر ۲۴h و نمودار مینی |

| `/orderbook SYMBOL` | دفتر سفارش خرید و فروش |

### دستورات معاملات

| دستور | توضیحات |
|-------|---------|
| `/buy SYMBOL QTY PRICE` | سفارش خرید: مثلاً `buy BTC 10 500` |
| `/sell SYMBOL QTY PRICE` | سفارش فروش: مثلاً `sell BTC 5 600` |
| `/cancel ORDER_ID` | لغو سفارش باز |
| `/orders` | مشاهده سفارش‌های باز |

### دستورات حساب

| دستور | توضیحات |

### 💡 رابط کاربری تعاملی

علاوه بر دستورات متنی، بات دارای رابط کاربری دکمه‌ای (Inline Keyboard) است:
- دکمه‌های خرید/فروش برای هر ارز
- دکمه مشاهده نمودار
- دکمه دفتر سفارش
- دکمه‌های ناوبری بین بخش‌ها
- لغو سفارش با یک کلیک

## 📊 الگوریتم تطبیق سفارشات (Matching Engine)

### نحوه کار

```
  سفارش خرید ──────┐
                    ├──▶ تطبیق ──▶ اجرای معامله
  سفارش فروش ─────┘
```

### قوانین تطبیق

1. **اولویت قیمت**: خریداران با بالاترین قیمت و فروشندگان با پایین‌ترین قیمت در اولویت هستند
2. **اولویت زمان**: در صورت مساوی بودن قیمت، سفارش زودتر ثبت‌شده اولویت دارد
3. **قیمت اجرا**: معامله با قیمت سفارش موجود (به نفع سفارش‌دهنده جدید) اجرا می‌شود
4. **سفارش باز**: اگر تطبیقی صورت نگیرد، سفارش در دفتر سفارش (Order Book) قرار می‌گیرد
5. **رزرو موجودی**: هنگام ثبت سفارش خرید، مبلغ رزرو و هنگام فروش، دارایی رزرو می‌شود
6. **لغو سفارش**: سفارش باز قابل لغو است و مبلغ/دارایی رزرو شده بازگردانده می‌شود
7. **تطبیق جزئی**: امکان پر شدن بخشی از سفارش وجود دارد

### مثال تطبیق

```
دفتر سفارش BTC:
  خرید:  10 واحد @ 500  │  5 واحد @ 490
  فروش:   8 واحد @ 520  │ 12 واحد @ 530

→ کاربر سفارش خرید 15 واحد @ 530 می‌گذارد
→ 8 واحد با قیمت 520 تطبیق (ارزان‌تر!)
→ 7 واحد باقیمانده در Order Book
```

## 🎁 سیستم جایزه روزانه

| ویژگی | توضیحات |
|-------|---------|
| زمان توزیع | هر شب ساعت ۲۴:۰۰ به وقت تهران (UTC+3:30) |
| شرط دریافت | ارزش کل دارایی < ۵,۰۰۰ سکه |
| مبلغ جایزه | ۱,۰۰۰ سکه |
| محدودیت | یک بار در روز |
| اطلاع‌رسانی | پیام شخصی به کاربر |

### محاسبه ارزش دارایی
```
ارزش کل = موجودی نقد + (تعداد هر ارز × قیمت فعلی)
```

## 🛡️ سیستم ضد تقلب (Anti-Cheat)

### روش‌های شناسایی

| روش | توضیحات |
|-----|---------|
| **Fingerprint** | شناسایی دستگاه بر اساس اطلاعات کاربر |
| **شناسایی چند اکانت** | اکانت‌هایی با fingerprint مشترک به هم متصل می‌شوند |
| **جلوگیری از Self-Trading** | جلوگیری از خرید/فروش بین اکانت‌های یک نفر |
| **تشخیص Wash Trading** | هشدار هنگام خرید و فروش مکرر یک ارز در ۵ دقیقه |
| **تشخیص حساب جدید** | هشدار برای معامله بزرگ از حساب تازه‌ثبت‌نام |
| **پرچم‌گذاری** | حساب‌های مشکوک Flag می‌شوند و ادمین می‌تواند بررسی کند |

### اقدامات
- اکانت‌های مرتبط (Alt Accounts) شناسایی و به هم متصل می‌شوند
- Self-Trading بین اکانت‌های مرتبط بلاک می‌شود
- ادمین از طریق `/flagged` می‌تواند حساب‌های مشکوک را ببیند
- ادمین می‌تواند با `/ban` حساب متقلب را بن کند

## 📝 نکات فنی

- **زبان**: C# (.NET 8.0)
- **فایل واحد**: تمام کد در یک فایل `SahamBot.cs`
- **بدون وابستگی خارجی**: فقط از System.Net.Http و System.Text.Json استفاده شده
- **Polling**: از Telegram Long Polling استفاده شده (بدون نیاز به Webhook)
- **Unicode**: پشتیبانی کامل از زبان فارسی
- **Rate Limiting**: تأخیر ۵۰ms بین ارسال پیام‌های Broadcast
